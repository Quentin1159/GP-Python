BASE LUNAIRE — calcul et affichage séparés

Conserver les deux .py et donnees_energie.json dans le même dossier.
1. Installer : python3 -m pip install matplotlib
2. Premier terminal dans ce dossier : python3 calculateur.py
3. Deuxième terminal : python3 production.py
Le graphique peut aussi être lancé en premier : il attend le JSON.
Ctrl+C dans le premier terminal arrête le calculateur. Fermer le graphique
n'arrête pas le calculateur et inversement.

Le JSON fourni contient uniquement la mesure initiale t=0.
Chaque lancement du calculateur recommence à t=0 et remplace le JSON.
Lancer un seul calculateur à la fois pour ce fichier.

Dans calculateur.py :
- delta_t_H = 1 : un point par heure ; 0.5 : deux points par heure.
- H_par_s = 10 : dix heures simulées par seconde réelle.
- puissance_solaire() : modèle fictif de production à modifier.
- puissance_consommation() : besoins fictifs constants de 40 kW à modifier.
- historique_H : durée de conservation du JSON (1416 h par défaut).

Dans production.py : abscisse_H, ordonne_kWH, refresh_ms et les couleurs
ne règlent que l'affichage. L'échelle verticale s'élargit si nécessaire.
Le temps du graphique vient du JSON ; aucun deuxième chronomètre simulé.
Les fichiers sont recherchés à côté des scripts, quel que soit le dossier
depuis lequel on les lance.

Chaque valeur énergie_produite/consommée correspond à l'intégrale de la
puissance entre t-1 h et t. L'unité est kWh. À t=0, le modèle est appliqué
sur [-1,0] : production nulle et consommation de 40 kWh.
Avec un pas de 0.5 h, les fenêtres d'une heure se chevauchent : ne pas
additionner tous ces points pour obtenir un total énergétique.
Le graphique affiche seulement la production ; la consommation est déjà
calculée et disponible dans le JSON.
